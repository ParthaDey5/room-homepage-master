# Room Homepage - Frontend Mentor Challenge

This is my solution to the **Room Homepage** challenge from [Frontend Mentor](https://www.frontendmentor.io). The goal was to build out an e-commerce homepage and make it look as close to the provided design as possible, while ensuring responsiveness and interactivity.

---

## 🚀 Overview

### The Challenge
Users should be able to:
- View the optimal layout depending on their device’s screen size
- See hover states for all interactive elements
- Navigate the image slider using mouse/trackpad or keyboard

### Screenshot
- ./capture.png

---

## 🛠️ Built With
- **HTML5** – semantic structure
- **CSS3 / TailwindCSS** – responsive styling and transitions
- **JavaScript (ES6+) / React** – slider functionality and component-based structure
- **Vite** – fast development build tool

---

## ⚡ Features
- Responsive design for mobile, tablet, and desktop
- Smooth sliding animations for hero images (left/right navigation)
- Keyboard accessibility for slider navigation
- Hover states for buttons and interactive elements

## ⚙️ Setup & Installation

1. Clone the repo:
   ```bash
   git clone https://github.com/ParthaDey5/room-homepage-master.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```
